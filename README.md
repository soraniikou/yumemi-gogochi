このアプリについて
指がふれた回数も、間も、どれくらい待ったかも、
どこにも残りません。
このページを閉じれば、すべては夜の中に還ります。
作った私自身も、それを知ることはできません。
記録も、分析も、評価もない。
ただ、あなたと夜だけの時間です。
一度タップ後　20分自動的に音がなります。
🌃スマホのデイスプレイを明るさ調整し、暗くしていただくと、画面は　より黒っぽくて暗くなるので、寝付きに良いかもしれません。
